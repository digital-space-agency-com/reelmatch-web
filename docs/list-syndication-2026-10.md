# Lists for Letterboxd, IMDb and Pinterest (Oct 2026)

Why: for the searches our guides target, user-made lists rank on page one: IMDb lists are often #1-2, and Letterboxd lists are #6 for "scary movies to watch with friends" and "feel good movies" and #9 for "thanksgiving movies" (OpenSEO, 9 Oct 2026). Each list points back to the full guide, so a list that outranks our page still sends people to us.

How to post:
- **Letterboxd** (letterboxd.com → Lists → Start a new list): paste the title and description, add the films in order, and tick "Ranked list". Letterboxd descriptions allow links. Add reelmatch.app to the profile "Website" field. Bio: "We make ReelMatch, a free app where you swipe movie trailers with friends and see what you all said yes to."
- **IMDb** (imdb.com → Your lists → Create a new list): same title, description and order. IMDb strips most links from descriptions, so write the URL as plain text (it still helps people find the guide).
- **Pinterest**: create a board "Movie night ideas" and pin each image from `docs/pinterest/` with the title, description and the guide URL as the pin link.
- Add a one-line note per film only if you have time; the order and title do most of the work.
- Post as the ReelMatch brand account, not a personal one, so it's clear who made it.
